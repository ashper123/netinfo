# CLI Options Reference

| Flag | Description |
|---|---|
| `--json` | Output machine-readable JSON object |
| `--sweep` | Perform 64-worker parallel ping sweep before listing LAN devices |
| `--vendors` | Perform online MAC OUI vendor lookups via `api.macvendors.com` |
| `--no-dns` | Skip reverse-DNS hostname resolution for maximum speed |
| `--no-color` | Disable ANSI color formatting |
| `--save FILE` | Export network report snapshot to a JSON file |
| `--compare FILE` | Compare current network state against a saved snapshot file |
| `--version` | Display version string |
